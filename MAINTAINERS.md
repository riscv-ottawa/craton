# Maintainers

A maintainer reviews pull requests, merges them, and answers for what lands in `main`.
Craton has no per-directory ownership yet, so every maintainer is responsible for the whole tree.
Areas will be split out here once the design is large enough that one reviewer cannot cover it.

## Changing this list

Add yourself in a pull request that appends one row, signed off like any other commit, and approved by a maintainer already listed.
Step down the same way, with a pull request that removes your row.
